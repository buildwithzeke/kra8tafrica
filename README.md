# KRA8T Africa

Africa's Student Career Operating System, built as a responsive Next.js, Tailwind CSS, and Iconify prototype.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Iconify React

## Included Product Areas

- Dashboard with Career Readiness Score
- AI Career Advisor
- Roadmap Generator
- Learning OS
- Opportunity OS
- Community OS
- Portfolio Builder
- Startup Hub

## Structure

- `app/page.tsx` coordinates app state and renders views.
- `components/AppShell.tsx` owns the responsive sidebar, topbar, and search shell.
- `components/*.tsx` contains reusable feature sections and UI primitives.
- `components/data.ts` stores prototype data.
- `components/types.ts` stores shared TypeScript types.
